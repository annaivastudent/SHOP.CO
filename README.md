# SHOP.CO

SHOP.CO is a modern fashion landing page built with React and Vite. The website features a stylish design with fashion collections, new arrivals, promotional offers, and an interactive shopping cart counter.

## Features

- **Landing Page** – single-page layout with multiple fashion sections.
- **Navigation Menu** – links to different sections of the landing page.
- **Product Catalogue** – display of clothing items with images, names, and prices.
- **Shopping Cart** – add and remove products.
- **Quantity Management** – increase and decrease the quantity of selected products.
- **Dynamic Cart Counter** – automatically updates the total number of selected items and displays it in the navigation bar.
- **Promotional Banners** – special offers and discount campaigns.
- **Trending Collections** – featured fashion collections.
- **Newsletter Subscription** – email subscription section.
- **App Promotion** – mobile app promotional section.
- **Footer** – company information, useful links, and social media icons.

## Technologies

- React
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd SHOP.CO
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided by Vite in your browser.
